# gogoga Table

[English](https://github.com/JackWeiGogoga/gogoga-table/blob/main/README.md) | **简体中文**

Notion、飞书文档那样的表格：好看，点格子就能改，底色、列宽一拖一点就好。文件里仍然是标准的 Markdown 表格，没装插件、在手机上、在 GitHub 上打开都是正常表格。

界面语言跟随 Obsidian 的语言设置，支持简体中文和英文。桌面端和移动端都能用。

## 用法

装好就生效：笔记里的 Markdown 表格在实时预览和阅读视图里都换成 gogoga Table 的样子，不用改任何写法。

- **改内容**：单击格子选中，直接打字替换；双击或按 Enter 在原内容上改。编辑中 Enter 完成并走到下一行，Shift+Enter 在格子里换行，Tab / Shift+Tab 左右走，Esc 取消。最后一格按 Tab 自动加一行。
- **选中时**：方向键移动，Delete 清空，⌘Z / ⌘⇧Z 撤销重做（和编辑器是同一条历史）。第一行再往上、最后一行再往下、Esc，光标回到表格外面的正文。
- **加行加列**：鼠标移到表格上，右边和下边出现加号。
- **行、列手柄**：鼠标停在格子上，这一行的左边框、这一列的上边框出现手柄，点开是行 / 列菜单：插入、上下左右移动、整行整列设底色、删除；列菜单里还有对齐和自动列宽。
- **右键格子**：插入行列、对齐、底色、清空、删除行列。
- **列宽**：拖表头的右边缘，双击恢复自动。
- **底色**：灰、红、橙、黄、绿、蓝、紫七种，取主题的颜色调淡，深浅色模式下都合适。
- **手机**：点一下格子就进入编辑，长按出菜单，滑动照常滚动。
- 格子里的加粗、链接、`[[双链\|别名]]`、标签、公式照常显示，点链接直接打开。

## 设置

- **接管 Markdown 表格**（默认开）：关掉后完全恢复 Obsidian 原生表格。
- **样式**：默认（参考 Notion：直角、极淡的分隔线、表头浅底）、斑马纹、极简线。
- **行距**：舒适、紧凑。

## 文件里存的是什么

表格本身是标准 GFM 表格，对齐用标准的 `:---:` 写法。Markdown 写不出来的列宽、底色，放在紧跟表格下面的一行 HTML 注释里：

```markdown
| 方案 | 月费 | 存储 |
| :--- | :---: | ---: |
| 基础 | 10 元 | 5 GB |
<!-- gogoga-table: {"w":[120,null,200],"bg":{"B2":"yellow"}} -->
```

- 坐标按 Excel 的习惯：列是 A、B、C，第 1 行是表头。增删、移动行列时，注释里的坐标跟着改。
- 注释在别的编辑器里看不见；在 Obsidian 里由插件藏起来。注释放在表格下面，是因为放在上面紧贴着时，没装插件的 Obsidian 实时预览不把它当表格。
- 没有列宽、底色时不写注释。注释坏了或被删掉，表格照常显示，只是没有列宽和底色。
- 原来补了空格对齐的表格，改完仍然对齐（中文按两个字宽算）；两头没写竖线的表格，写回时也不加。

## 目前的范围

- 只接管顶格写的表格。代码块、引用和 callout（`>` 开头）、列表里缩进的表格，仍由 Obsidian 原生显示。
- 紧跟在一段文字后面（中间没空行）的表格不接管，交给 Obsidian 原样处理。
- 合并单元格、多格选区、和 Excel / 飞书互相复制粘贴、拖动行列在后续版本。
